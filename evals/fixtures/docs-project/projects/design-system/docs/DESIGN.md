# DESIGN — 現在有効な構造決定

分野の入口兼正本である。現在有効な原則、境界、決定を短く持ち、詳細は下位文書へ案内する。
定性的な良し悪しの判断は`PRODUCT_SENSE.md`が所有し、ここには置かない。

## 原則

- 部品は状態を持たず、状態は呼び出し側が持つ。
- 例外的な見た目はpatternsで表現し、primitivesへ分岐を足さない。

## 境界

- tokensは値だけを持ち、意味づけはprimitives以上が持つ。
- 1部品が2つ以上の責務を持ったら分割する。

## 現在有効な決定

- 間隔は4pxグリッドに固定する（2026-07-12）。
- ダークテーマはtokensの切替だけで成立させる（2026-07-20）。
